# 📊 Análise Exploratória dos Municípios de Minas Gerais

Projeto desenvolvido para a disciplina de **Introdução à Ciência de Dados**, do curso de **Estatística da Universidade Federal de Minas Gerais (UFMG)**.

O trabalho realiza uma **análise exploratória de dados dos municípios de Minas Gerais**, utilizando indicadores demográficos, sociais e econômicos disponibilizados pelo **IBGE**.

A análise foi desenvolvida em **R** e apresentada por meio de um relatório produzido com **Quarto**, contendo estatísticas descritivas, visualizações, análise de correlações e mapas interativos.
